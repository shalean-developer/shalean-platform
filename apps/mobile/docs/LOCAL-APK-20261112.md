## Build environment and recovery

A full JDK 17, Android SDK 35, build tools 35.0.0, NDK 27.1.12297006,
CMake 3.22.1 and Gradle 8.13 were available/installed locally. The initially
selected Java 21 runtime lacked `javac`; the downloaded JDK also needed this
host's system trust store for its network proxy. Certificate verification stayed enabled.

The Gradle daemon disappeared during Metro and Ninja compilation; memory
pressure was the working diagnosis, supported by the successful lower-memory retry. The local build path now limits Metro/Gradle workers, checks `javac`, and
uses CMake compile/link pools. On this constrained host the app C++ stage still
needed separation: stop Gradle, run the generated app Ninja build with `-j1`,
then rerun release assembly with the same CMake configuration and a 1024 MiB
Gradle heap. All 64 app native build steps completed, then assembly succeeded.
The final manual Gradle invocation explicitly inherited all staging env values;
the saved local build script already loads and exports them before invoking Gradle.
This evidence covers the phased build; it does not claim an uninterrupted fresh
run of the convenience script on this host.
