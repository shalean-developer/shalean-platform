## Requirements (approved design scope)

| Capability | Notes |
|------------|-------|
| Every X days | Integer interval ≥ 1 |
| Every X weeks | Interval + optional selected weekdays |
| Every X months | Interval + optional day-of-month or weekday-in-month rule |
| Selected weekdays | Mon–Sun multi-select when weekly/custom-week |
| Optional end | End date **or** visit count (exactly one required for generation bound) |
| Human-readable preview | e.g. “Every 2 weeks on Tue & Thu until 15 Dec 2026 (12 visits)” |
| Availability | First visit uses same Step 2 availability; subsequent visits generated by recurring engine with cleaner/team continuity rules |
| Generation implications | Must reuse existing recurring series tables; conflict handling; customer edit/cancel semantics |

## Out of scope for current remediation release

- UI control for custom frequency beyond existing weekly/fortnightly/monthly
- Partial implementation of interval editors without generation + preview
